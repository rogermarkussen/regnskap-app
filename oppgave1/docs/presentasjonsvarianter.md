# Oppgåve 1 – valt dashboardretning

Den mellombelse samanlikninga av fem presentasjonsvariantar er avslutta.
Dashboardet har no éi fast retning: mørk blå topp, lys filterflate, finansiering
som hovudstruktur og kompakte KPI-kort med budsjettspor.

## Prinsipp

- Dei ni avtalte KPI-ane er innhaldet; dashboardet legg ikkje til nye analysar.
- `154301` er hovudområdet, medan `154345` og `154322 / 045101` er sekundære.
- Seksjon blir filtrert med rekneskapsdimensjonen `dim_1` og namn frå `C1`.
- Rapportperiode blir vald med Evidence `ButtonGroup`.
- Budsjettspor og status viser forholdet mellom hovudbok og budsjett utan
  dekorative diagram.
- Variantveljar og designforklaringar er fjerna frå den publiserte flata.

Retninga er laga for rask avlesing på vanleg arbeidsskjerm og legg KPI-korta i
éin kolonne på mobil.
